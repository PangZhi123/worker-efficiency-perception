# 施工人员工效智能感知：可行性与首版设计

## 结论

采用 Ultralytics YOLO Pose + ByteTrack 可实现人员检测、17 点姿态骨架、短时身份跟踪和轨迹输出。结合单应性标定，可以把人员脚点投影到总平图并完成工作区进出、区域人数与合规时长统计。

通用姿态模型不能可靠推断“是否真正施工”。首版因此将 `WORKING` 定义为人员经滞回确认后处于工作区域内；关键点用于可视化、锚点增强和证据回放，不直接虚构动作语义。若后续要识别搬运、操作设备、停工等动作，应增加带现场标注数据的时序动作分类器。

## 算法链路

1. YOLO Pose 检测人员并输出人体框和 COCO 17 个关键点。
2. ByteTrack 给出视频内短时 `trackId`；它只用于展示和轨迹关联，不作为跨遮挡、跨摄像头的永久身份。
3. 优先使用左右脚踝中点作为人员地面锚点，低置信度时退化为人体框底边中心。
4. 使用至少四组相机点/总平图点计算单应矩阵，将锚点投影到总平图归一化坐标。
5. 点在多边形判断产生候选工作区，进入/离开持续时间阈值形成滞回状态，抑制边界抖动。
6. `INSIDE` 人员计入 `actualWorkingCount`。达到 `expectedWorkerCount` 的连续时间累计为 `qualifiedTeamWorkDurationSec`。

## 已实现范围

- Ultralytics Pose + ByteTrack 结果适配器；
- 脚踝/框底锚点；
- 单应性投影和边界包含的多边形判断；
- `OUTSIDE/ENTERING/INSIDE/LEAVING/UNKNOWN` 状态机；
- 丢轨容忍、人数合规和班组合格工效时长累计；
- 与规范字段对应的人员和区域结果结构；
- 不依赖 GPU/模型文件的单元测试。

## 验收建议

- 标定平均重投影误差建议小于 3 px，最大误差阈值按相机分辨率现场确定；
- 人员检测召回率、区域人数准确率、进出事件 F1、合规时长绝对误差分别验收；
- 至少覆盖遮挡、蹲姿、脚部出画、夜间、反光服、边界徘徊和 `trackId` 切换样本；
- 工效统计应按视频时间戳累计，不按推理耗时累计；长帧间隔必须截断，防止断流虚增工时。
